# Theme implementation notes

This folder is reserved for PS4 theme source and packaging configuration.

Before producing an installable package, verify:
1. The exact custom-theme format and required metadata.
2. Supported wallpaper, icon, colour, and audio asset formats.
3. Package size and image-dimension limits.
4. Whether the packaging tool supports the target firmware and GoldHEN environment.

Do not assume an animated GIF, MP4, or ordinary desktop wallpaper can be used directly as a PS4 dynamic theme. Confirm the format from reliable documentation and test independently.

No installable package is included yet.
