# TV TIME packaging readiness

## Scope

The repository now produces a **static PS4 theme staging tree** with a `theme.xml` descriptor and a separate **experimental dynamic-scene candidate**. The static tree preserves the Tenna home wallpaper and the red/yellow function-screen background. CI validates the generated PNGs, descriptor, manifest, dynamic scene, and original WAV music master.

The pipeline stages an optional binary `sce_sys/param.sfo`, generates a theme GP4 project description, audits the inputs, and includes a theme-specific `.pkg` maker wrapper. The maker calls a separately supplied compatible `orbis-pub-cmd` executable; the proprietary tool and its adjacent `ext/` folder are not bundled. The repository has not yet generated a production `.pkg` or proved compatibility with the target console. A staging folder, audit report, GP4 file, or ZIP is not an installable theme.

## Default static staging layout

`build/tv-time/Image0/` contains:

- `theme.xml` — format-version 4.0 descriptor; red system theme colour (`themecolor=2`), yellow focus accent (`#FFFFD400`), warm-white text, transparent dimmers.
- `texture/background/homescreen.png` — Tenna-inspired wallpaper.
- `texture/background/functionscreen.png` — red/yellow static background.
- `texture/preview.png` — theme thumbnail.
- `texture/function_icon/` — four mapped icons and glow variants.
- `sce_sys/icon0.png` — theme-list icon.
- `sce_sys/pic1.png` — 1920×1080 theme image.
- `sce_sys/param.sfo` — optional binary package metadata, staged only when supplied via `--param-sfo`.
- `sound/bgm_home.at9` — optional, only when a converted AT9 is supplied.
- `STAGING-MANIFEST.json` — dimensions, modes, byte sizes, SHA-256, descriptor and optional-audio/SFO state.

A separate intermediate input, `build/tv-time/package-input/param.sfx`, is generated by `tools/build_param_sfx.py`. CI stores its validation-only sample as `param-ci-fixture.sfx` so it cannot be mistaken for a TV TIME production ID. It carries the typed theme package metadata used by the binary SFO writer; it is not itself the binary `sce_sys/param.sfo`.

The theme descriptor uses the maintained reference project's documented XML shape. The values are implementation choices for TV TIME, not a guarantee that every theme field behaves identically on every system-software release.

The `homebgm-enable` flag remains `False` by default. The WAV master is not a PS4 home BGM asset; the theme only enables music when a non-empty `.at9` file is supplied.

## Generate and review

Requirements: Python 3.10+, Pillow, and CairoSVG.

```bash
python -m pip install -r requirements-packaging.txt
python tools/prepare_assets.py
python tools/validate_staging.py
python tools/make_review_sheet.py --staging build/tv-time/Image0 --output build/tv-time/review-sheet.png
python tools/preview_home_ui.py --wallpaper build/tv-time/Image0/texture/background/homescreen.png --output build/tv-time/home-ui-preview.png
```

To use converted home music, first create the original WAV master and convert it with a compatible, separately obtained Sony `at9tool`. The encoder is proprietary and is not bundled or redistributed here.

```bash
python tools/generate_home_bgm.py
python tools/convert_home_bgm.py --at9tool /path/to/your/at9tool
python tools/prepare_assets.py --at9 build/tv-time/sound/bgm_home.at9 --force
python tools/validate_staging.py
```

`--at9` accepts an already-converted `.at9` file, not a WAV. It is size-checked and copied to `Image0/sound/bgm_home.at9`; the descriptor then enables home music. The converter checks WAV format, uses the requested 144 kbps loop settings, and checks the output size, but playback still needs real-console testing.

Use `--force` only when intentionally replacing an existing staging directory.

The validator checks all 13 PNG assets, formats, dimensions, manifest metadata and hashes; validates the required theme descriptor fields and palette; and verifies that the home-music flag matches the presence of the optional AT9 file.

Generate the metadata input using a title ID selected for this theme:

```bash
python tools/build_param_sfx.py --title-id CUSA12345 --output build/tv-time/package-input/param.sfx
```

`CUSA12345` is an example only, not an ID reserved for TV TIME. The generator validates the ID shape and builds a 36-character content ID using the default `UP9000` prefix and `TVTIME0000000000` edition code. Choose a title ID that does not conflict with another package before creating the final metadata. The CI pipeline stores its `CUSA00000` sample as `param-ci-fixture.sfx`; it is only a validation fixture and must not be used as the production package identity.

Convert the XML input into a binary PSF file:

```bash
python tools/build_param_sfo.py --input build/tv-time/package-input/param.sfx --output build/tv-time/package-input/param.sfo
```

The writer creates the standard PSF 1.1 header, index records, aligned key table and typed data table, then parses the file back and compares its values with the XML source. To include it in a theme staging tree, supply it using `--param-sfo`:

```bash
python tools/prepare_assets.py --output build/tv-time/production/Image0 --param-sfo build/tv-time/package-input/param.sfo
python tools/validate_staging.py --staging build/tv-time/production/Image0
```

CI generates a clearly named `param-ci-fixture.sfx` and `param-ci-fixture.sfo` using `CUSA00000` only as a validation fixture, then creates and validates a separate fixture `Image0` tree. Do not use those fixture files as the production package identity. The binary writer is structurally self-validated, and the staging validator checks its bytes, hash, title ID and content ID. It has not yet been tested by the target console.

## GP4 project description

Once a staging folder includes a valid binary SFO, generate the plain XML GP4 project:

```bash
python tools/build_gp4.py --staging build/tv-time/production/Image0 --output build/tv-time/package-input/tv-time.gp4
```

The generator checks the theme descriptor, SFO theme identifiers, SFO hash/size metadata and the exact staging file list. It excludes `STAGING-MANIFEST.json` from the package file list and writes a `pkg_ps4_theme` volume with no application chunk metadata. The result is only a GP4 project description; it does not invoke a package tool or create a `.pkg`. CI creates a separate GP4 fixture using the validation-only `CUSA00000` identity.

## Pre-package input audit

After generating an `Image0` tree with a real, non-conflicting title ID and building its GP4 description, run:

```bash
python tools/audit_package_inputs.py \\
  --staging build/tv-time/production/Image0 \\
  --gp4 build/tv-time/package-input/tv-time.gp4 \\
  --output build/tv-time/package-input/package-input-audit.json
```

The audit re-checks the theme palette, manifest hashes, SFO identity and theme category, optional AT9 state, and exact GP4-to-staging file inventory. It writes a JSON report containing a SHA-256 and byte count for each package input. It refuses the CI-only `CUSA00000` identity by default; `--allow-ci-fixture` exists only for explicit fixture validation, and the report labels that result as fixture-only. The audit report is stored outside `Image0` and is not added to the theme package. Passing this audit does not itself create a `.pkg` or prove console compatibility.

## Build the theme .pkg

The repository includes `tools/build_theme_pkg.py`, which wraps the theme-capable `img_create` and `img_file_list` commands. It uses the already-generated `pkg_ps4_theme` GP4 and the theme-specific SFO metadata (`CATEGORY=ac`, `IRO_TAG=2`). Do not substitute a generic app-package builder that rewrites the SFO as a game/application; a correctly formed theme package must retain the theme metadata.

The external tool is not included in this repository. Supply a compatible `orbis-pub-cmd` executable with its adjacent `ext/` directory. On Windows, the default location is `tools/orbis-pub-cmd.exe`. On Linux, use the Windows executable through Wine:

```bash
python tools/build_theme_pkg.py \\
  --staging build/tv-time/production/Image0 \\
  --gp4 build/tv-time/package-input/tv-time.gp4 \\
  --output build/tv-time/package-output/TV-TIME.pkg

# Linux with a separately installed Wine and a compatible Windows toolchain:
python tools/build_theme_pkg.py \\
  --staging build/tv-time/production/Image0 \\
  --gp4 build/tv-time/package-input/tv-time.gp4 \\
  --output build/tv-time/package-output/TV-TIME.pkg \\
  --orbis-pub-cmd /path/to/orbis-pub-cmd.exe --wine
```

The builder also accepts `ORBIS_PUB_CMD` as the executable path environment variable, `--timeout` to set the build timeout, `--report` to choose the JSON report path, and `--force` to replace existing outputs. The default output report is `TV-TIME.pkg.build.json` beside the package.

Before starting, it re-runs the package-input audit and rejects the CI-only `CUSA00000` fixture. It then runs `img_create --no_progress_bar --tmp_path ... --oformat pkg ...`, checks for a valid PS4 PKG header, and runs `img_file_list --passcode ...` using the passcode in the GP4. The package listing must contain every staged file. It also checks that `param.sfo`, `icon0.png`, and `pic1.png` are stored under `Sc0/`, while the actual theme files remain under `Image0/`, and that the staging manifest is not packaged.

The wrapper's unit tests use a stub tool to test command construction, file placement, failed builds, invalid headers and missing entries. CI does not include the proprietary toolchain and therefore does not produce a real `.pkg`. A passing build/listing check establishes package structure only; installation, theme application, firmware compatibility and audio playback still require real-console testing. The production title ID must be chosen before generating the final SFO and package.

## Separate dynamic-scene candidate

Run:

```bash
python tools/build_dynamic_scene.py --output build/tv-time-dynamic
```

The candidate contains twelve 640×360 DXT1 frames, `plane.mdx`, and RAF `index.xml`. It is **not merged into the default static theme**. When a RAF scene is active, it replaces both the home and function background screens. That would hide the Tenna wallpaper as the actual home background, so the default TV TIME variant remains static; the animation is retained as an alternate compatibility experiment.

See [DYNAMIC-SCENE-POC.md](DYNAMIC-SCENE-POC.md) for its structure, limits, and testing boundary.

## Limitations

- The UI overlay preview is illustrative, not an exact PS4 capture.
- Network and Media remain concept artwork until their correct slots are verified.
- The dynamic scene is structurally validated in CI but has not been accepted or displayed by the target CUH-1115A / reported firmware 14.02.
- No game-ripped artwork or soundtrack is bundled.
- Console model and firmware details are user-reported; no compatibility guarantee is made.
