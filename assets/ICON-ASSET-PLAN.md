# Icon Asset Plan

The icon direction is defined; production exports are pending confirmation of the exact PS4 theme icon requirements.

## Visual system
- Rounded broadcast panels with a midnight-violet base.
- Cyan and magenta neon edge accents.
- Simple, high-contrast silhouettes that remain recognizable at small sizes.
- Minimal text; avoid putting the full TV TIME title inside every icon.

## Initial icon concepts
| System area | Concept |
|---|---|
| Settings | Tuning dial / broadcast sliders |
| Network | Signal arcs |
| Friends | Two-screen link |
| Messages | Broadcast envelope |
| Media | Play symbol inside a CRT |
| Power | Standby symbol with ON AIR accent |

## Export rules
Do not guess final pixel dimensions, colour mode, alpha handling, or file format. Confirm them from a reliable PS4 theme specification before exporting. Keep editable SVG masters in this repository and place final raster exports in a clearly named build directory.
