# Asset guidelines

## Visual direction
- Primary title: **TV TIME**
- Secondary identity: **TENNA BROADCAST NETWORK**
- **Base theme palette: red and yellow.** Use near-black/charcoal for contrast, broadcast red for major frames and ON AIR indicators, and bright signal yellow for titles, highlights, and channel graphics.
- Suggested core colours: broadcast red `#ED1C24`, signal yellow `#FFD400`, near-black `#100707`, warm white `#FFF8E5`.
- Motifs: CRT scanlines, signal noise, broadcast frames, channel numbers, television glass.

## Planned deliverables
- Home-screen wallpaper master: 1920×1080.
- Preview image: 16:9.
- Icon artwork: dimensions and formats to be confirmed against PS4 theme specifications.
- Optional audio: formats and size limits to be confirmed.

## Credits and licensing
Keep a source/credit note for every third-party image, font, sound, and other asset. Prefer original artwork and properly licensed resources. Do not commit ripped game assets or copyrighted soundtrack files without permission.


## System background master
- Red/yellow Flow-style system background concept: `tv-time-system-background-red-yellow-v0.1.svg` (1920×1080 SVG master).
- This is separate from the TV TIME title-card wallpaper.
- It is an original static concept master, not yet converted to or validated as a PS4 theme resource.


## Animated system background source
- `tv-time-flow-motion-study.svg` is a looping, 1920×1080 animated SVG motion study for the red/yellow Flow-style system background.
- It is a visual source master only. The PS4 does not install this SVG directly; the scene must be rendered into supported frames and assembled into the PS4 background-scene format.
- Keep this source separate from the static fallback and title-card wallpaper.


## Home-screen wallpaper options
- Preferred default: `tv-time-home-screen-wallpaper-v0.2.svg` — original Tenna-inspired TV-showman composition, 1920×1080, with the main character on the right and clear space on the left for PS4 home-screen tiles.
- Existing alternate: `tv-time-wallpaper-v0.1.svg` — simpler TV TIME title-card composition.
- Both are original SVG source masters; export and verify the exact PS4 wallpaper format/dimensions before packaging.
