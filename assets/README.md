# Asset guidelines

## Visual direction
- Primary title: **TV TIME**
- Secondary identity: **TENNA BROADCAST NETWORK**
- Palette: midnight violet, electric cyan, magenta, and small red ON AIR accents.
- Motifs: CRT scanlines, signal noise, broadcast frames, channel numbers, television glass.

## Planned deliverables
- Home-screen wallpaper master: 1920×1080.
- Preview image: 16:9.
- Icon artwork: dimensions and formats to be confirmed against PS4 theme specifications.
- Optional audio: formats and size limits to be confirmed.

## Credits and licensing
Keep a source/credit note for every third-party image, font, sound, and other asset. Prefer original artwork and properly licensed resources. Do not commit ripped game assets or copyrighted soundtrack files without permission.
